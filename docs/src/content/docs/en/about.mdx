slotsmith is created and maintained by Tareq Al-Mozayek (طارق المزيك), a frontend-focused full-stack engineer based in Damascus, and published on npm under the ISC license. This page is about him, how to reach him, and what the library builds next.

## Author

Tareq Al-Mozayek is a frontend-focused full-stack engineer working in React, Next.js and TypeScript. He builds web apps in React, Next.js, Vue and Nuxt, with backends in Laravel and Filament, and holds a BSc in Information Technology (Software Engineering) from Damascus University. slotsmith is his open-source component library.

## What comes next

slotsmith is a set of components, not a single one. Everything that follows keeps the same rule: headless logic, parts you can replace, and fallbacks finished enough to ship on their own, so a component fits whatever design system a project already has.

Today that is the [data table](../components/data-table/), the [autocomplete](../components/autocomplete/), the [date picker](../components/date-picker/) and the [file uploader](../components/file-uploader/). The [roadmap](../roadmap/) lists what is planned. Is there a component you wish existed? [Email the component you would like next](mailto:tareqmozayek@gmail.com).
