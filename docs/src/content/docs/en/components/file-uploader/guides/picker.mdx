Leave out the `upload` prop and the file uploader is a picker: nothing is sent, and `onFilesChange` hands you the picked `File` objects. Use it when the files go out with the rest of a form, in one request you write.

Pick or drop two files, then send the form: the line under it lists what the request would carry. Nothing is uploaded.

## What a picker does

Without [`upload`](../../api/#prop-upload) every item stays `ready`, and the item shows its name and size but no status. Everything else works as in an uploader: the drop zone, the [constraints](../validation/), the image previews and the Remove button.

- [`onFilesChange`](../../api/#prop-onFilesChange) is called with every picked file after each change, removals included.
- [`onValueChange`](../../api/#prop-onValueChange) gives the full items instead, and `getFiles(items)` turns them into files.
- [`multiple`](../../api/#prop-multiple) is off by default, like the native input: a second pick replaces the first file.

## Sending the files

Build the request from the files you were handed: append each one to a `FormData`, as the demo does in its submit handler, and send it with `fetch` or your form library.

In a plain HTML form, give the uploader a [`name`](../../api/#props). Its root then keeps a hidden file input of that name holding every file the uploader has, picked or dropped, so the form sends them as `<input type="file" name>` would: `new FormData(form).getAll(name)` returns them, and a form posted without script sends them as `multipart/form-data` (set `encType` on the form).

Pick or drop files and press Send: the form's own `FormData` lists them. Only files picked in this browser are sent; a file shown from a URL, such as one uploaded earlier, has no file to send.

## Custom text

The demo replaces two [labels](../../api/#labels): the zone's [`title`](../../api/#label-title), and the [`hint`](../../api/#label-hint) under it. The hint is a function that receives the limits (`accept`, `maxSize`, `maxFiles`) already formatted; the default joins them, as in "image/\*, .pdf · up to 5 MB".
