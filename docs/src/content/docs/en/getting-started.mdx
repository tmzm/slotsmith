Getting started with slotsmith takes one package and, if you want the default look, one stylesheet import. Then render a component: [`DataTable`](../components/data-table/), [`Autocomplete`](../components/autocomplete/), [`DatePicker`](../components/date-picker/) or [`FileUploader`](../components/file-uploader/). Themes, dark mode and languages are optional steps on top.

## Install

<Tabs id="install" tabs={[{ label: "npm", sample: "install/npm" }, { label: "pnpm", sample: "install/pnpm" }, { label: "yarn", sample: "install/yarn" }, { label: "bun", sample: "install/bun" }]} remember="pm" label="Package manager" lang="en" />

slotsmith works with React 18 and 19. Its peers are optional and per component, so you install only what the components you import need:

- The [data table](../components/data-table/) needs `@tanstack/react-table` 9.
- The [virtual rows](../components/data-table/guides/virtual-rows/) of `VirtualDataTable` also need `@tanstack/react-virtual` 3.
- The autocomplete, the date picker and the file uploader need nothing more.

The package itself depends on `@floating-ui/react-dom`, which places the popups; your package manager installs it with slotsmith.

## Styles

Every component renders plain HTML with stable class names, and the stylesheet that styles them is optional. Pick one of three:

- **Everything.** One import styles all four components.
- **One component.** Each component has its own sheet, `slotsmith/<component>.css`.
- **None.** When you replace every part with your design system's own, import no stylesheet: the components never reference it.

## Theming

The stylesheet reads a small set of shared `--ss-*` tokens, so a few values restyle all four components at once: set them on `:root` after the stylesheet. Or import one of the ready-made themes, which set the same tokens. Pick one here to see it on the components:

## Dark mode

The stylesheet and every theme have a dark palette. It applies under `.dark` or `[data-theme="dark"]`, on `<html>` or on any element above the components, so an app whose dark mode already sets one of those needs nothing more. The preview above follows this site's theme switch the same way. Following the system setting instead is covered in [Theming](../theming/#dark-mode).

## Languages

English is built in. For another language, import its pack and pass it as `locale`, or give a whole app one with `SlotsmithProvider`:

<SampleCode name="getting-started/provider" />

Each pack is its own entry, so an app loads only the languages it imports. The components follow the CSS direction of the page around them, so a right-to-left language also needs `dir="rtl"` on `<html>` or a wrapper. [Languages](../languages/) lists every pack and shows custom locales and one-off labels.

## Next.js and Vite
